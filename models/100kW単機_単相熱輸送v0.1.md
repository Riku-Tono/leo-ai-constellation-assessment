## 2. 流体・管材・式

比較流体は**約60°Cの液体水を物性の参照点**とする。宇宙機外部ループに水を採用する判断ではない。停止時の凍結、起動、蒸気圧、漏洩、材質適合はTBD。[NISTのIAPWS水物性表](https://nvlpubs.nist.gov/nistpubs/Legacy/IR/nistir5078.pdf)に基づき`ρ_f=983 kg/m³`、[NISTの粘度評価](https://srd.nist.gov/JPCRD/jpcrd121.pdf)に基づき`μ=0.000467 Pa·s`へ丸める。`c_p=4.0 kJ/(kg K)`は既存台帳から維持した**比較用仮定**で、水の精密な60°C熱容量値ではない。温度変化に伴う物性変化も省く。

剛体管は316L系を比較材とし、`ρ_p=8000 kg/m³`は[メーカー公表値](https://www.alleima.com/en/technical-center/material-datasheets/tube-and-pipe-seamless/alleima-3r60/)。肉厚`t=1.0 mm`、内面粗さ`ε=0.015 mm`、ポンプ・電動機・駆動効率`0.50/0.90/0.95`（合成0.4275）は**設計仮定**である。

```text
ṁ_loop = (100 kW/2) / (c_p ΔT_fluid)
D_o = D_i + 2t
v_i = ṁ_i / (ρ_f πD_i²/4),  Re_i = ρ_f v_i D_i / μ
f_i = 0.25/[log10(ε/(3.7D_i)+5.74/Re_i^0.9)]²   (Swamee–Jain、乱流)
Δp_straight,path = Σ_path f_i (L_i/D_i) ρ_f v_i²/2
M_wall = Σ_all ρ_p (π/4)(D_o²−D_i²)L_i
M_fill = Σ_all ρ_f (π/4)D_i²L_i
P_electric,straight = 2 Δp_straight,path (ṁ_loop/ρ_f) / 0.4275
```

Darcy–Weisbachと摩擦係数近似は[米EPAの水理資料](https://nepis.epa.gov/Exe/ZyPURL.cgi?Dockey=P100S9AS.TXT)と同じ形。全行の最小Reは4,000超。**質量は全186 m、圧損は各並列枝のうち一つを通る経路**で積算し、枝8本の圧損を直列加算しない。

仮の設計差圧1.0 MPaと許容膜応力100 MPaでは、`σ_hoop≈pD_i/(2t)`は最大内径40 mmで20 MPa、単純膜応力からの必要厚さは0.20 mm。100 MPaは本計算の**仮定許容値**であり、メーカー公表の50/100°Cでの0.2%耐力200/180 MPaから飛行認定を導いたものではない。1 mm管は座屈、疲労、腐食、溶接、継手、試験圧、最高温度を未確認。

## 4. 未積算の圧損、電力、質量

```text
Δp_total,path = Δp_straight,path + ΣK_i ρ_f v_i²/2
              + Δp_coldplate + Δp_radiator_channel
              + Δp_deployment_joint + Δp_flexible + Δp_other
P_pump,electric = 2 Δp_total,path (ṁ_loop/ρ_f) / 0.4275
```

冷却板・パネル内流路、展開継手/可撓管、分岐/曲がり/弁/フィルタの圧損は**TBD**。圧損の仮の一律上乗せはしない。未知圧損だけを**50/150/300 kPa/系の仮定感度**で振ると、中径10 Kの全圧損は112.8/212.8/362.8 kPa/系、全2系の電力は0.67/1.27/2.16 kW。直管分0.37 kWも完成ポンプの必要電力ではない。実ポンプの流量―揚程―効率曲線、NPSH、寿命、宇宙適格性と質量はTBD。

この電力はまず既存の補機17.65 kW枠に配分する。通信、PCDU損失、姿勢制御等との**合計**が枠を超えた場合だけ、`P_total`、太陽電池、電池、放熱面とそれらの質量を更新する。二重加算しない。

**中径10 Kの186.2 kgは剛体管壁とその内部の水だけ**。ポンプ、冷却板、パネル内チャンネル、可撓管、継手、弁、フィルタ、アキュムレータ、支持具、断熱材、補機放熱系は0 kgでなくTBD。パネル1.726 tとの条件付き加算で総熱系質量を名乗らない。片面/両面放射と8 kg/m²に含まれる部材が分かるまで、パネル内チャンネル等の質量を二重計上しない。

次は冷却板・パネル内チャンネルの熱抵抗と圧損、展開継手の実配置、凍結に耐える流体選定、実ポンプの仕様をそろえる。流体入口/出口の`ΔT_fluid`を接合部→平均放熱面の35.5 Kへ丸ごと足すことはせず、各位置の温度と面内放射分布を解く。35.5 Kへの収まり、完全冗長化、総熱系質量、5 t/8 t仮枠への収まりは未判定。これらが閉じてから代替ラジエーター技術と比較する。
